Review your PC patch

    Downloading does not change your PC. Running the file without arguments shows a preview.

    View the exact script 
    
      
    
      
    
        Run after review
        
    Open PowerShell as administrator in the folder containing the downloaded file.
    
        
    powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\security-suite-patches.ps1
    
        
    To apply the displayed changes:
    
        
    powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\security-suite-patches.ps1 -Apply
    
        
    RemoteSigned applies only to that PowerShell process. If Windows marks the download as blocked, review it, then open its file Properties and choose Unblock. Organization policy may require a signed script.
    
        
    Run a fresh Quick scan afterward. The patch checks each result and stops if verification fails.
    
      
    
      
    
        Backup and rollback
        
    Applying saves a log and the previous LLMNR and AutoRun values beside the script, in SecuritySuite-Backups. Rollback for those two policies uses the backup path printed by the script:
    
        
    powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\security-suite-patches.ps1 -Apply -RollbackFrom '.\SecuritySuite-Backups\RUN-ID\registry.json'
    
        
    Other patch types need manual recovery. The script never restarts Windows automatically.
